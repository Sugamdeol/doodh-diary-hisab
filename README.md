# 🥛 Doodh Diary Hisab

A **PWA for dairy farmers** to log daily milk production, track charts & stats, and manage monthly *hisab* (settlements) — built for low-end devices and designed for rural India.

🌐 **Live:** [doodhhisabsd.vercel.app](https://doodhhisabsd.vercel.app)

## ✨ Features

- 📝 Daily milk entry logging (morning/evening, per animal or vendor)
- 📈 Production charts and stats dashboard
- 🗓️ Monthly settings and hisab management
- 📱 Installable PWA — works offline-first with a service worker
- 🇮🇳 Built for dairy farmers: simple UI, Hindi-friendly

## 🛠️ Tech Stack

- **React 18** · **TypeScript** · **Vite**
- **shadcn/ui** + **Tailwind CSS** + **Radix UI**
- **Recharts** for charts · **React Query** · **React Hook Form**
- PWA: manifest + service worker

## 🚀 Getting Started

```bash
git clone https://github.com/Sugamdeol/doodh-diary-hisab.git
cd doodh-diary-hisab
npm install
npm run dev
```

Build for production with `npm run build`.
